## 💡 PRG 2025 카카오 하반기 2차 - 선인장 숨기기 [[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/468379)]

| 항목 | 내용 |
|------|------|
| 문제 유형 | `Sliding-Window` |
| 사용 알고리즘 | `Monotonic Deque`, `2D Sliding Window Minimum` |
| 난이도 | `Lev.2` |

### ✅ 문제 설명

**[문제 요약]**

- m × n 크기의 격자가 있으며 왼쪽 위 좌표는 (0, 0)이다.
- 격자 내부에 회전할 수 없는 h × w 크기의 선인장 구역을 배치한다.
- 비구름은 drops에 주어진 순서대로 격자의 서로 다른 칸에 비를 뿌린다.
- 빗방울이 처음으로 선인장 구역 내부에 떨어지는 시점이 해당 선인장이 처음 비를 맞는 시점이다.
- 선인장이 가능한 한 늦게 비를 맞도록 선인장 구역의 위치를 결정해야 한다.
- 끝까지 비를 맞지 않는 위치가 존재하면 해당 위치가 가장 높은 우선순위를 가진다.
- 동일한 시점에 처음 비를 맞는 후보가 여러 개라면 가장 위쪽에 있는 구역을 선택한다.
- 행도 같다면 가장 왼쪽에 있는 구역을 선택한다.
- 최종적으로 선택한 선인장 구역의 왼쪽 위 좌표를 반환한다.

**[제약 사항]**

- 1 <= m, n <= 500,000
- 1 <= m × n <= 500,000
- 1 <= h <= m
- 1 <= w <= n
- drops[i] = [r, c]
- drops[i]는 i + 1번째 빗방울이 떨어지는 위치를 의미한다.
- 모든 빗방울은 서로 다른 칸에 떨어진다.

### 🔍 풀이 접근

- 가장 단순한 방법은 모든 h × w 선인장 배치 후보를 확인하는 것이다.
- 각 후보 영역 내부를 순회하며 가장 먼저 떨어지는 빗방울의 순서를 찾으면 해당 선인장이 처음 비를 맞는 시점을 알 수 있다.
- 하지만 모든 후보에 대해 h × w 영역을 매번 순회하면 중복 계산이 매우 많이 발생한다.
- 먼저 각 격자 칸에 빗방울이 떨어지는 시점을 저장한다.
- 비가 떨어지지 않는 칸에는 INF를 저장한다.
- 그러면 특정 h × w 선인장 영역이 처음 비를 맞는 시점은 해당 영역 내부 값의 최솟값이 된다.
- 따라서 문제는 모든 h × w 부분 행렬의 최솟값을 구한 뒤, 그중 가장 큰 값을 가지는 위치를 찾는 문제로 변환할 수 있다.
- 1차원 배열의 고정 크기 구간 최솟값은 Monotonic Deque를 이용하면 전체를 O(N)에 구할 수 있다.
- 이를 2차원으로 확장하여 행 방향으로 Sliding Window Minimum을 수행한 뒤, 결과 배열에 대해 열 방향으로 다시 Sliding Window Minimum을 수행한다.

### 💡 핵심 로직

[Sliding Window Minimum]

- 새로운 값이 들어오면 deque 뒤에서부터 현재 값보다 큰 값을 제거한다.
- Window 범위를 벗어난 index는 deque 앞에서 제거한다.
- deque의 맨 앞에는 항상 현재 Window의 최솟값 index가 존재한다.
- 이를 통해 세로 방향으로 압축된 배열을 만든다.



### 📌 배운 점
- 2차원 구간 문제를 1차원 구간 문제에서 확장하여 해결할 수 있음을 배웠다.
- Sliding Window에서 이전 Window의 최솟값 하나만 저장하는 것이 아니라, 앞으로 최솟값이 될 가능성이 있는 후보들을 Monotonic Deque로 관리한다는 점을 이해했다.

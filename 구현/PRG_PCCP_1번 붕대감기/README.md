### ✅ 문제 설명
**[문제 요약]**

- 붕대 감기: t초 동안 붕대를 감으면 1초마다 x만큼 체력을 회복
- t초 연속으로 붕대를 감는 데 성공하면 y만큼 추가 체력 회복
- 최대 체력을 넘을 수는 없음
- 기술을 쓰는 도중 공격을 당하면 기술이 취소됨
- 공격을 당하는 순간에는 체력을 회복할 수 없음
- 몬스터에게 공격당해 기술이 취소당하거나 기술이 끝나면 즉시 붕대 감기를 다시 사용하며, 연속 성공 시간 0
- 현재 체력이 0이하가 되면 캐릭터가 죽으며 더 이상 체력을 회복할 수 없음
- 모든 공격이 끝난 직후 남은 체력을 return하는 문제

**[제약 사항]**

- 캐럭터의 체력이 0이하가 되어 죽는다면 -1을 리턴
- attacks의 공격 시간은 모두 다름
- 1 <= health <= 1,000
- health는 최대 체력
- 1 <= 공격 시간 <= 1,000
- 1 <= 피해량 <= 100


### 🔍 풀이 접근

- 그냥 시뮬레이션 문제

### 💡 핵심 로직

- 시전 시간: casting_time
- 초당 회복량: recovery_per_second
- 추가 회복량: additional_recovery_amount
- 최대 체력: health
- attacks: (공격 시간, 피해량)
- 연속 성공 횟수: cnt
- init() -> 현재 시간 t = 0 / cnt = 0
- loop()
	- t++
	- 만약 t == attacks.공격 시간 -> 현재 체력 -= 피해량 -> 만약 현재 체력 <= 0 -> 루프 탈출
	- 변화량 += recovery_per_second
	- 만약 cnt == casting_time -> 변화량 += additional_recovery_amout
	- 현재 체력 += 변화량
	- 현재 체력이 >= health -> 현재 체력 = health

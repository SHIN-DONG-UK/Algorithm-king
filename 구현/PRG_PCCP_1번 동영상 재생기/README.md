### ✅ 문제 설명
**[문제 요약]**

- 동영상 재생기에는 10초 전 이동, 10초 후 이동, 오프닝 건너뛰기 3가지 기능을 지원
- 10초 전 이동: "prev" 명령을 날림 / 현재 위치가 10초 미만이면 0분 0초로 이동
- 10초 후 이동: "next" 명령을 날림 / 동영상 남은 시간이 10초 미만이면 마지막 위치로 이동
- 오프닝 건너뛰기: 현재 재생 위치가 오프닝 구간(op_start <= 현재 재생 위치 <= op_end)인 경우 자동으로 오프닝이 끝나는 위치로 이동
- 동영상의 길이, 기능이 수행되기 직전의 재생위치, 오프닝 시작 시간, 오프닝 끝나는 시간, 사용자 입력이 주어짐
- 사용자 입력이 모두 끝난 후 동영상의 위치를 "mm:ss" 형식으로 return하는 문제

**[제약 사항]**

- video_len 길이 = pos 길이 = op_start 길이 = op_end 길이 = 5
- 모든 입력은 "mm:ss" 형식으로 주어짐
- 0 <= mm <= 59
- 0 <= ss <= 59
- 비디오의 현재 위치 혹은 오프닝이 끝나는 시각이 동영상 범위 밖인 경우는 주어지지 않음
- op_start < op_end
- 1 <= commands 길이 <= 100
- commands의 원소는 "prev" 혹은 "next"

### 🔍 풀이 접근

- commands의 명령을 순차적으로 처리하는 시뮬레이션 + 구현 문제
- "mm:ss"인 형식을 초 단위로 바꿔서 문제를 해결하면 쉬울 것으로 보임

### 💡 핵심 로직

- video_len, pos, op_start, op_end를 모두 초단위 정수로 바꾼다
- commands를 순차적으로 수행한다
- 초단위 정수인 결과를 다시 "mm:ss" 형식으로 변환한다

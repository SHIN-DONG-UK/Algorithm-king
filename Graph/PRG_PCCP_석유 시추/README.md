## 💡 PRG PCCP - 석유 시추 [[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/250136)]

| 항목 | 내용 |
|------|------|
| 문제 유형 | `그래프 탐색` |
| 사용 알고리즘 | `BFS` |
| 난이도 | `Lev.2` |

### ✅ 문제 설명
**[문제 요약]**

- n x m 격자가 있음
- 격자에 석유가 묻혀 있고, 여러 덩어리로 나뉘어져 있음
- 시추관을 수직으로 단 하나만 뚫을 수 있음
- 시추관은 열 하나를 관통하는 형태
- 가장 많은 석유를 뽑을 수 있는 시추관의 위치를 찾는 문제

**[제약 사항]**

- 1 <= n, m <= 500


### 🔍 풀이 접근

- BFS를 이용해서 덩어리를 탐지해야 함
- 처음에 한 번 BFS 싹 돌려서 캐싱해놓고, 이 캐싱된 데이터에서 최댓값을 찾는 설계가 중요
- 근데 덩어리에 속한 모든 요소가 자신의 덩어리 크기를 알아야 함
- 아니면 그냥 시추를 하고 매번 BFS를 돌리는 방향도 있음
- 덩어리의 각 요소를 방문하면서 스택이나 어디 자료에 넣어놓고 BFS 탐색 다 끝나면 덩어리 크기 쭉 써주면 되겠네


### 💡 핵심 로직

- 2차원 격자를 모두 방문한다
- 1이면 BFS를 시작한다
- BFS 탐색 시, 방문할 때마다 해당 노드를 스택에 저장해둔다
- BFS 탐색이 종료되면, 해당 덩어리 크기를 스택에 있는 모든 노드에 기록한다
- 단, 같은 덩어리임을 구분할 수 있도록 key도 함께 기록한다
- 2차원 격자에 캐싱한 정보들로부터 시추관 탐색을 시작한다
- 모든 열을 탐색하면서, 최댓값을 갱신한다
- 덩어리 key값으로 중복 탐색을 피한다

### 📌 배운 점
- 풀이 후 모든 격자의 정보를 저장할 필요는 없고, 덩어리가 걸치는 열 정보에 바로 계산 결과를 합치는 리팩터링 가능성을 확인했습니다.

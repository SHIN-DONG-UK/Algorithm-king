## 💡 PRG PCCP - 3번 아날로그 시계[[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/250135)]

| 항목 | 내용 |
|------|------|
| 문제 유형 | `수학` |
| 사용 알고리즘 | |
| 난이도 | `Lev.2` |

### ✅ 문제 설명
**[문제 요약]**

- 시침, 분침, 초침이 있는 시계가 있음
- 이 시계는 초침이 시침/분침과 겹칠 때마다 소리가 남
- 특정 시간동안 알림이 울린 횟수를 알고 싶음

**[제약 사항]**

- 0 <= h1, h2 <= 23
- 0 <= m1, m2 <= 59
- 0 <= s1, s2 <= 59

### 🔍 풀이 접근
- 00:00:00부터 시각 t까지 알림이 울린 횟수를 세는 함수 count(t)가 있다고 하자
- start ~ end 사이의 횟수는 count(end) - count(start)로 표현할 수 있다
- 단, count(start)에 알람이 울린다면, count(end) - count(start) + 1을 해야 한다
- 시침을 몇 번 만났는지, 분침을 몇 번 만났는지 따로 계산할 수 있다
- A(t) = 00:00:00 ~ t 동안 초침과 분침이 만난 횟수
- B(t) = 00:00:00 ~ t 동안 초침과 시침이 만난 횟수
- 즉, count(t) = A(t) + B(t)
- 단, 시침, 분침, 초침이 한꺼번에 겹치는 시점에서는 횟수를 중복하게 세게 되므로, 이 경우를 빼줘야 한다
- 최종 count(t) = A(t) + B(t) - C(t)

### 💡 핵심 로직

- 특정 구간을 직접 시뮬레이션하지 않고 `0~t`까지의 알람 횟수를 계산하는 `count(t)`를 정의
- 두 바늘이 만나는 문제를 상대각속도 문제로 변환
  - 초침-분침: 상대각도 `59t/10`
  - 초침-시침: 상대각도 `719t/120`

### 📌 배운 점
- 두 물체의 주기적인 만남을 구할 때 각각의 위치를 시뮬레이션하기보다 상대속도와 주기를 먼저 생각해보자
- 입력이 정수라고 사건도 정수 시점에 발생하는 것은 아니다
- 정수와 정수 사이에 사건이 발생할 수 있다

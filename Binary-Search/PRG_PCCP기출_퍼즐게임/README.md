## 💡 PRG PCCP기출문제 - 퍼즐게임 [[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/340212)]

| 항목 | 내용 |
|------|------|
| 문제 유형 | `Binary-Search` |
| 사용 알고리즘 | `Parametric Search` |
| 난이도 | `Lev.2` |

### ✅ 문제 설명
**[문제 요약]**

- n개의 퍼즐을 제한 시간 내에 풀어야 함
- 각 퍼즐은 난이도와 소요 시간이 정해져 있음
- 현재 퍼즐의 난이도를 diff, 현재 퍼즐의 소요 시간을 time_cur, 이전 퍼즐의 소요 시간을 time_prev, 숙련도를 level이라고 하면, 다음과 같이 게임이 진행됨

- diff <= level이면 퍼즐을 틀리지 않고 time_cur만큼의 시간을 사용하여 해결함
- diff > level이면, 퍼즐을 총 diff - level번 틀리는데, 퍼즐을 틀릴 때마다 time_cur만큼 시간을 사용하고 추가로 time_prev만큼 시간을 사용해 이전 퍼즐을 풀고와야 함
- 단, 이전 퍼즐을 다시 풀 때는 이전 퍼즐의 난이도에 상관없이 틀리지 않음
- diff - level번 틀린 이후에 다시 퍼즐을 풀면 time_cur만큼의 시간을 사용하여 퍼즐을 해결함

- 퍼즐 게임에는 전체 제한 시간 limit이 정해져 있음
- 제한 시간 내에 퍼즐을 모두 해결하기 위한 숙련도의 최솟값을 구하려고 함

**[제약 사항]**

- 난이도, 소요 시간 그리고 숙련도는 자연수
- 1 <= diffs의 길이 = times의 길이 = n <= 30만
- diffs[0] = 1 (항상 틀리지 않음)
- 1 <= 난이도 <= 10만
- 1 <= 소요 시간 <= 1만
- 1 <= limit <= 1e15
- 제한 시간 내에 퍼즐을 모두 해결할 수 있는 경우만 입력으로 주어짐

### 🔍 풀이 접근
- 문제의 크기 n 은 최대 30만
- 숙련도를 이분탐색으로 test하는 식으로 문제를 해결할 수 있음
- 문제의 난이도는 최대 10만이고, 숙련도 또한 최대 10만까지만 고려하면 됨
- 임의의 숙련도를 test해보고 이 숙련도로 limit 내에 가능하면 숙련도를 줄이면 된다
- 이 숙련도가 가능하면, 그 이상의 숙련도는 모두 제외해도 상관없다
- 따라서 이분탐색처럼 문제를 해결하면 된다
- Parametric Search 문제

### 💡 핵심 로직

- 숙련도 k에 대해 test 함수
- 숙련도 k를 조절하는 이분 탐색 루프
